# Audit: `main`

Target: `main` at `96a2783` (merge of PR #16). Audited from a clean detached worktree. Read-only; nothing from the experiments is committed.
Briefs used: root-level `*.md` files (`design.md`, `audit.md`, `contract.md`, ...) plus `docs/tasks/*.md` and `docs/afaw-light.md`.

## 1. Verdict

- **Safe with fixes.** `precheck` passes on a clean checkout, the tree stays clean after the tests, mock data is deterministic and the population model matches an independent recomputation.
- **Blocker for the next step:** model code exists (`model/src/argmodel/population`) but there is no `docs/model-design.md`, so the model cannot be checked against a design (check 21).
- **Process claims are partly false:** `LASTCONTEXT.md` says strict TDD was followed, but tests and implementation were committed together; Python tests never read the golden vectors and three mutations survived.
